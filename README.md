# Mon portfolio développeuse web 

Ce projet est mon portfolio en ligne. Il présente mon profil, mes compétences et une sélection de projets que j’ai réalisés en développement web.

## Fonctionnalités

- Présentation de mon profil et de mon parcours
- Section compétences (front-end, back-end, outils)
- Liste de projets avec liens (dépôts GitHub, démos en ligne)
- Page de remerciement / confirmation après envoi de formulaire 
- Design responsive (adapté aux écrans ordinateur et mobile)

## Stack technique

- **HTML5** – structure des pages (`index.html`, `merci.HTML`, etc.)
- **CSS3** – mise en forme et mise en page (dossier `Style/`)
- **JavaScript** – interactions et logique côté client (dossier `JS/`)
- **Assets** – images et documents (dossiers `image/` et `Doc/`)
- **Hébergement** : Netlify

## Objectifs du projet

Ce portfolio a été créé pour :

- Présenter mon profil d’étudiante en développement web
- Mettre en valeur mes projets (projets de cours et projets personnels)
- Servir de support pour mes candidatures (stage, alternance, premier emploi)

Ce projet m’a permis de pratiquer :

- l’intégration HTML/CSS,
- l’organisation d’un site statique multi‑pages,
- un peu de JavaScript pour les interactions,
- le déploiement d’un site sur Netlify.
